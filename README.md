# Instamart-Average-Order-Analysis 
Analysis of Instamart region-wise Average Order Value showing top 20 regions

A Python data analysis project that calculates and visualizes **Average Order Value (AOV)** across different regions using Instamart customer order data.


## Overview
This project analyzes customer order data to identify **top-performing regions based on AOV**.
It helps in understanding regional spending patterns and business performance.

## Dataset
* Source: Kaggle -Instamart Customer Dataset
* File Used: `Instamart_customers.csv`

## Tech Stack
* Pandas– data loading, cleaning, and aggregation
* Matplotlib– plotting graphs
* Seaborn– enhancing visualization aesthetics

## Output
Top 20 regions based on Average Order Value (AOV)
